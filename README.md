
# 🛍️ Shopping App

A modern iOS Shopping App built using **Swift and UIKit**. This project demonstrates user authentication using Firebase along with multiple UIKit components such as **Scroll View, Table View, Collection View, Stepper, and Tab Bar**.

## 🚀 Features

### 🔐 Firebase Authentication

* User Sign Up
* User Sign In
* Password Reset functionality
* Incorrect password validation
* A red error message label is displayed when the user enters an incorrect password
* The error label remains hidden when the password is correct

### 📱 User Interface

* Scroll View implementation
* Table View for displaying content
* Collection View for displaying products or items

### 🖼️ Banner Slider

* An upper banner slider implemented using a **Stepper**
* The banner image changes when the Stepper value changes
* The banner can also change based on the selected table view cell

## 🛠️ Technologies Used

* Swift
* UIKit
* Firebase Authentication
* Xcode
* UITableView
* UICollectionView
* UIScrollView
* UIStepper

## 🔧 Installation

1. Clone this repository.
2. Open the project in Xcode.
3. Install the required dependencies.
4. Configure Firebase using your `GoogleService-Info.plist` file.
5. Build and run the application on an iOS Simulator or a physical device.
